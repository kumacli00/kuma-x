1. クマ・目元を投稿の8割に戻す

根拠：プロフィールクリック率 0.51% 対 0.19%（2.6倍）／ 現状は40%

最も効く型が、投稿の半分以下（40%）しか使われていません。時事や業界批判を全部やめる必要はありませんが、比率を逆にするだけで、同じ本数から来る人の数が変わります。

  • クマの原因別（茶・青・黒）の違いを、1本1テーマで書く
  • 症例の前後と、その人がどう見えるようになったかを1本ずつ
  • 「脱脂（＝目の下のふくらみの原因になっている脂肪を取る施術）だけで足りる人／足りない人」のような、判断の分かれ目を書く

2. 返信を減らし、そのぶんを「引用」に振り替える

根拠：返信87本＝全体の41%で、インプレッション寄与は3.3%

「引用」は、他人の投稿にこちらのコメントを足して、自分の投稿として出すことです（X の投稿画面で、相手の投稿の下にある引用ボタンから出せます）。ただ相手に返事をするだけの「返信」と違い、自分のフォロワーのタイムラインにも流れます。

返信は届く相手が近いぶん効率は良いのですが、量が出ません。同じ内容を引用で出せば、相手にも届いたうえでタイムラインにも流れます。作業量はむしろ減ります。

  • 返信で長文を書きそうになったら、引用に切り替える
  • 返信は「相手への礼儀として必要なとき」に限る

3. バズが来た日に、受け皿を出す

根拠：2026-08-27のバズは1,517,465インプレッションでプロフィールクリック731回（0.048%）

バズそのものは止められませんし、止める必要もありません。問題はそこに来た人を受け止める投稿がなかったことです。伸びている投稿にぶら下げる形で、クマ治療の投稿を続けて出せば、通りすがりの一部は残ります。

  • 数字が伸び始めたら、その日のうちに自分のスレッド（＝自分の投稿に自分で返信してつなげた連なり）へクマの投稿をつなぐ
  • 固定投稿（＝プロフィールの一番上に貼っておける1本）を「クマ治療の入口になる1本」にしておく

4. プロフィールと固定投稿を作り直す

根拠：33日で5,882回プロフィールが見られている＝ここが最大の接点

5,882回も見られている場所です。ここで「何ができる人か」「どこに行けばいいか」が3秒で分かるかどうかで、その先が変わります。

5. 予約までの道すじに計測をつなぐ

根拠：プロフィールから先が1件も測れていない（05節）

プロフィールのリンクにパラメータ（＝リンクの末尾に付ける、どこから来たかの目印）を付け、予約フォーム側で受け取るだけです。半日で終わり、以降は「Xから何人来たか」が毎月わかるようになります。いま最も情報量が増える作業です。

6. 1日3本を、毎日に均す

根拠：1日中央3本／最大33本／投稿ゼロが11日

まとめ出しと沈黙を繰り返すより、同じ本数を毎日に散らすほうがタイムラインでの露出は安定します。本数を増やす必要はありません。

この数字について

  • 出典は X の API（＝X が用意している、数字を機械で受け取る窓口） v2。アカウント本人としてログインして取得しています。対象は @kumacli_mohri の2026-07-04〜2026-09-07の投稿213本です。リポスト（＝他人の投稿をそのまま拡散すること。旧リツイート）は除いています。
  • プロフィールクリックは全期間ぶんはありません。対象は2026-08-06〜2026-09-07の73本で、それ以前の140本は空のままです。理由は X の仕様ではなく、こちらの取得スクリプトがこの指標を保存していなかったことです。2026年9月8日に修正して取り直せるぶんは回収しましたが、それより古い投稿は X 側から取り直せず、埋められません。以降は取得のたびに記録されます。この窓に期間最大のバズが含まれている点も、読むときに考慮してください。
  • プロフィールのリンククリック数はほとんど取得できていません（全期間213本のうち数字が返ってきたのは4本だけ、うち1回以上あったのは1本）。ファネルの下2段が「—」なのはこのためです。
  • テーマ分類は、本文にその言葉が入っているかだけで仕分けた機械分類（＝人が読んで分けたのではなく、言葉が入っているかで機械的に仕分けたもの）です。「クマ・目元の治療」はクマ／目の下／下眼瞼（＝かがんけん＝下まぶた）／脱脂（＝目の下のふくらみの原因になっている脂肪を取る施術）／ハムラ（＝目の下のふくらみを、へこみのほうへ移して段差をならす手術）など、「業界への注意喚起」は過剰脱脂（＝目の下の脂肪を取りすぎて、かえってくぼんでしまった状態）／直美（＝ちょくび＝研修を終えてすぐ美容医療へ進んだ医師）／被害／拡散希望などで判定しています。取りこぼしはあります。
  • 同じ分類名でも、表によって本数が違います。「全期間66日・213本」の表と、「プロフィールクリックが取れている33日・73本」の表が混在しているためです。どちらの表かは、各表の上に書いてあります。
  • インプレッションは投稿後も伸び続けます。直近の投稿は数字が確定していません。
  • フォロワー数の推移は今回から記録を開始しました。次回以降のレポートで増減を出せます。
  • 中央値（本数ぶんを良い順に並べて、ちょうど真ん中に来る1本の数字）を主に使っています。1本のバズで平均が壊れるため、平均値は「普段の実力」を表さないからです。
